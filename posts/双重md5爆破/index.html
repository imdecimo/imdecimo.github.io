双重md5加密弱等于

当前做过几道php反序列化题目中含有md5双重加密的判断

发现有两个小知识点

科学计数法弱等于

比如说这道极客大挑战2025的题目，要求两个值弱等于且不强等于。

由于弱等于可以把字符串转化为数字比较，而强等于限制了二者不能完全相同

所有用到科学计数法，当双重md5后字符串为0e开头后面全是数字，则可以通过弱比较，二者都等于0，且强比较不同，符合题意。这里给出一个python脚本，可以拿来爆破

 1import hashlib
 2import string
 3import multiprocessing
 4
 5def double_md5(s):
 6    first_md5 = hashlib.md5(s.encode()).hexdigest()
 7    second_md5 = hashlib.md5(first_md5.encode()).hexdigest()
 8    return second_md5
 9
10def is_magic_hash(md5_hash):
11    return md5_hash.startswith('0e') and md5_hash[2:].isdigit()
12
13def worker_task(args):
14    charset, length, start_idx, batch_size, max_results_left = args
15    results = []
16    count = 0
17    for i in range(start_idx, start_idx + batch_size):
18        if i >= len(charset) ** length or count >= max_results_left:
19            break
20        candidate_str = ''
21        temp = i
22        for j in range(length):
23            candidate_str += charset[temp % len(charset)]
24            temp //= len(charset)
25        hash_result = double_md5(candidate_str)
26        if is_magic_hash(hash_result):
27            results.append((candidate_str, hash_result))
28            count += 1
29    return results
30
31def parallel_brute_force(max_results, charset, desc=""):
32    max_length = 6
33    batch_size = 100000
34
35    found = []
36    print(f"\n开始并行暴力破解“{desc}”集，目标找到 {max_results} 个...")
37
38    for length in range(4, max_length + 1):
39        print(f"\n搜索长度 {length} 的字符串...")
40        total_combinations = len(charset) ** length
41
42        with multiprocessing.Pool(processes=multiprocessing.cpu_count()) as pool:
43            tasks = []
44            for start_idx in range(0, total_combinations, batch_size):
45                left_to_find = max_results - len(found)
46                if left_to_find <= 0:
47                    break
48                tasks.append((charset, length, start_idx, batch_size, left_to_find))
49
50            for i, result_batch in enumerate(pool.imap_unordered(worker_task, tasks)):
51                if result_batch:
52                    for string_val, hash_val in result_batch:
53                        print(f"找到匹配! 字符串: {string_val}, 哈希: {hash_val}")
54                        found.append((string_val, hash_val))
55                        if len(found) >= max_results:
56                            print("已达到目标数量，提前结束")
57                            pool.terminate()
58                            break
59                    if len(found) >= max_results:
60                        break
61                if i % 10 == 0:
62                    progress = min((i + 1) * batch_size, total_combinations)
63                    print(f"进度: {progress}/{total_combinations} ({progress/total_combinations*100:.1f}%)")
64        if len(found) >= max_results:
65            break
66
67    print(f"\n全部找到的魔术hash（{desc}）如下：")
68    for idx, (s, h) in enumerate(found, 1):
69        print(f"{idx:02d}. 字符串: {s}, 哈希: {h}")
70
71    return found
72
73if __name__ == "__main__":
74    num = int(input("请输入要找到的魔术hash数量: "))
75    print("-" * 30)
76    # 先用纯字母集爆破
77    results_alpha = parallel_brute_force(num, string.ascii_letters, desc="字母")
78    print("-" * 30)
79    # 再用字母+数字集爆破（不会重复已找到的结果）
80    results_alphanum = parallel_brute_force(num, string.ascii_letters + string.digits, desc="字母+数字")

数字前缀弱等于

如果出现条件：if (md5(md5(“x”)) == 114)

如果我们的字符串x的双重md5加密值为114开头且后面一位是字母(除e加数字外)，或者后面的两位是e+字母，则可以通过弱等于（PHP7）

这里给出一个python脚本用于爆破

 1import hashlib
 2
 3def double_md5(s):
 4    h1 = hashlib.md5(s.encode()).hexdigest()
 5    h2 = hashlib.md5(h1.encode()).hexdigest()
 6    return h2
 7
 8def brute_force(prefix, max_count=1, start=0):
 9    found = 0
10    i = start
11    prefix_len = len(prefix)
12    while found < max_count:
13        candidate = str(i)
14        result = double_md5(candidate)
15        if result.startswith(prefix):
16            # 第x+1位
17            if len(result) > prefix_len:
18                nxt1 = result[prefix_len]
19                # 满足：不是数字
20                if not nxt1.isdigit():
21                    print(f"第{found+1}个: 明文={candidate}, 双md5={result}")
22                    found += 1
23                # 如果第x+1位是e，则第x+2位不能是数字
24                elif nxt1.lower() == 'e' and len(result) > prefix_len + 1:
25                    nxt2 = result[prefix_len + 1]
26                    if not nxt2.isdigit():
27                        print(f"第{found+1}个: 明文={candidate}, 双md5={result}")
28                        found += 1
29        i += 1
30
31if __name__ == "__main__":
32    prefix = input("请输入你想要的双md5前缀：")   # 比如 '1145'
33    max_count = int(input("请输入最多爆破多少个：")) # 比如 2
34    brute_force(prefix=prefix, max_count=max_count)

因为“数字e数字”会被当成科学计数法解析，比如114e3会被解析为114000（114x10^3）
